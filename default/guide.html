更新日志 · v3.0.0
首个对外版本（适配 foo_ui_webview2 2.0.0）—— 这里只列要点
这一版做了什么
  • 适配插件 2.0.0：修掉 3 处会被严格校验拒绝的调用（进度跳转 / 「全部歌曲」/ 专辑封面），并接上实时声场、播放时钟、歌单 GUID、无边框小窗等新能力。
  • 入口重排：「更多」菜单收成四段（歌词 / 窗口 / 音频 / foobar2000，沿用旧版分区顺序），长内容折叠成组；低频项与排障工具搬进新增的「设置与工具」页（不占侧边栏）。
  • 频谱五种显示：频谱条 / 声场 / 瀑布图 / 示波器 / 矢量示波器，配统一的可视化调度器（多视图各自注册、暂停即停）。
  • 小窗（迷你播放器 / 歌词窗）：独立窗口 —— 主窗口最小化 / 进托盘时不再跟着消失，Win+D 也不收走；无响应自动关掉重开、无封面时用默认封面；排版、居中、DPI 尺寸、跨窗口设置归属都已修好。
  • 常驻托盘：图标 + 原生菜单（页面挂起时播放控制仍可用），左键单击 / 双击都把主窗口叫回前台。
  • 歌词与在线音源：歌词多源（LRCLIB / 网易云 / QQ）+ 候选面板；页内「QQ 音乐」「网易云」两个在线音源。
  • 修掉的一批问题：播放顺序点了「随机」实际下发成 shuffle-tracks、图标读不回真实档位（宿主 order 是序号不是 foobar 标志位）；换歌瞬间「保存歌词 / 嵌入标签」会把上一首的原文写进新曲目；「流派」页因多传参数被宿主整单拒绝（插件更新后接口变严格）；筛选零命中会显示整张歌单、筛选框的 × 常驻；「上次听歌的歌单」按名称恢复失效；进度条不可跳转时没有视觉反馈；DPI 变化只第一次能感知；小窗置顶按钮在失败时也点亮。
  • 移除自绘桌面歌词：桌面歌词仍走 ESLyric（显示 / 置顶 / 锁定 / 重置）。
  • 移除试听功能：右键的「试听（不加入歌单）/ 停止试听」与页内 <audio>、JIT 无痕试听整条链路全部删除（试听会与正常播放抢音频输出，宿主又没有可靠的失败信号），原位置换成「添加到插入队列」。
  • 插队队列（双轨制）：右侧改名并明确分工 —— 中间大列表 = 播放上下文（双击才切换），右侧 = 插队队列（原生播放队列，播完一首移一首、播完回上下文）。双击中间列表 /「播放全部」= 切上下文并清空插队队列；右键「下一首播放」插队首、「添加到插入队列」追加队尾，两者都不动中间列表；媒体库 / 发现 / 搜索的列表会映射进一个不显示在侧栏的 _MediaLibraryContext_ 歌单，播放时不再顶掉你正在看的歌单内容。
  • 播放历史（新）：插队队列上方的一行「播放历史」按钮，点开是从旧到新的只读时间线（默认 20 条、设置页可调，展开状态记住），最新一条紧贴"正在播放"，整条抽屉自上而下就是「过去 → 现在 → 接下来」；「上一首」优先回溯它，历史行双击回到那一条。

界面导览
了解 CloudMusic 主题的四大区域布局
侧边栏
搜索框、导航入口（发现/播放列表/搜索/媒体库）、歌单列表
主内容区
4 个标签页切换显示不同内容，播放列表含封面、曲目表格、排序
歌词面板
右侧面板，显示封面、曲目信息和同步歌词，可点击歌词行跳转
底栏
曲目信息、播放控制、进度条、音量、频谱、队列按钮
播放控制
播放/暂停、快进快退、音量调节、播放顺序
  • 播放/暂停：点击底栏中央播放按钮，或按 空格
  • 上一首/下一首：点击底栏切换按钮，或按 Ctrl+← / Ctrl+→
  • 取歌顺序（双轨制）：下一首先播右侧「插队队列」的队首，队列空了才按中间列表（播放上下文）的顺序走；上一首先回溯「播放历史」，历史到头才回到上下文上一首。自动播完同理：插队队列优先，播完回到中间列表当前的位置继续。手动「下一首」不受「单曲循环」影响（照常换歌，循环档位只作用于自动播完）。
  • 快进快退：按 ← 后退 5 秒，→ 前进 5 秒；也可拖动进度条
  • 音量：拖动音量滑块，或按 ↑ / ↓ 调节；按 M 静音
  • 播放顺序：点击底栏播放顺序图标，支持顺序播放、列表循环、单曲循环、随机播放
  • 播放后停止：在播放顺序菜单中可设置"播完当前曲目后停止"
播放列表
歌单管理、曲目排序、右键操作

播放列表是你的"收藏夹"，在侧边栏管理多个歌单，点击切换后在主区域查看曲目。

  • 新建歌单：侧边栏右键空白处或点击"+"按钮
  • 重命名/删除/清空：右键侧边栏歌单项
  • 排序：点击表头（标题/艺术家/专辑/时长/比特率）切换升序、降序、取消排序
  • 双击播放（切换播放上下文）：双击任意曲目 = 让这张歌单成为"当前在听的清单"并从这一首开播，右侧插队队列同时清空。歌单本身就是上下文，不需要任何同步
  • 插队（不动中间列表）：右键曲目 →「下一首播放」插到插队队首、「添加到插入队列」追加到队尾 —— 两者都不会切换中间列表，听完插队歌自动回到这张歌单继续
  • 右键调整顺序：右键曲目 →「调整顺序」— 上移 / 下移 / 移到顶部 / 移到底部；Ctrl 多选后可整组移动
  • 快捷键调整顺序：Alt+↑ / Alt+↓ 移动聚焦或选中的曲目
  • 更多操作：点击歌单封面旁"..."按钮 — 随机排列、按标题/艺术家排序、反转列表、撤销
  • 添加曲目到歌单：右键曲目 → "添加到歌单"；右键歌单 → "添加本地文件 / 添加文件夹"（文件夹会自动递归展开其中的音频文件）；或将音频文件 / 文件夹拖放到窗口任意位置
  • 从歌单删除：右键曲目 → "从歌单中删除"；Ctrl 多选后右键到已选中的曲目会整组删除（菜单会显示「从歌单中删除（N 首）」），或直接用底部批量栏的「从歌单删除」。锁定 / 自动歌单不提供该操作
播放上下文（双轨制）：中间大列表 = 播放上下文（当前在听的清单，决定默认播放顺序，双击才切换）；右侧小列表 = 插队队列（手动插的歌，优先级最高，播完一首移一首，播完回到中间列表继续）。
媒体库浏览
按歌曲、艺术家、专辑、流派多维度浏览

媒体库是 foobar2000 扫描的所有音频文件的集合，支持 5 种视图维度：

概览
显示媒体库统计数据：总曲目数、艺术家数、专辑数等
歌曲
按歌曲维度列表浏览，支持增量加载更多
艺术家
网格卡片展示，点击进入艺术家详情页查看其所有专辑和曲目
专辑
网格卡片展示，点击进入专辑详情页查看曲目列表
  • 进入详情：点击艺术家/专辑/流派卡片，进入后显示曲目列表和"播放全部"按钮
  • 双击播放（会切换播放上下文）：双击列表里的曲目（或点"播放全部"）= 把当前视图（这张专辑 / 这位艺术家 / 全部歌曲 / 这个文件夹）当作"当前在听的清单"，从你双击的那一首开始播，之后顺着这个视图往下走，右侧插队队列同时清空。视图在后台映射进一个不在侧栏显示的专用歌单（_MediaLibraryContext_），你自建的歌单不会被任何操作顶掉内容
  • 返回列表：点击返回按钮，滚动位置会自动恢复到之前的位置
  • 刷新媒体库：底栏「更多 → 设置与工具 → 刷新媒体库缓存」，重新扫描文件
搜索
在媒体库中快速查找曲目
  • 搜索入口：侧边栏搜索框（回车跳转搜索页）或切换到"搜索"标签页直接输入
  • 实时搜索：在搜索页输入框中输入，350ms 防抖后自动触发搜索
  • 搜索结果：显示匹配总数、封面、标题、艺术家·专辑、时长
  • 添加全部：搜索结果页提供"添加全部到歌单"按钮
  • 右键操作：搜索结果支持与播放列表相同的右键菜单（播放、添加到插入队列、下一首播放、添加到歌单等）；双击结果 = 把这次搜索结果当作"当前在听的清单"并从这一首开播（播放上下文，见 09 节）
歌词
同步歌词、纯文本歌词、点击跳转
  • 显示/隐藏：点击底栏歌词按钮或按 L 切换歌词面板，状态自动记忆
  • 同步歌词：带时间轴的 LRC 歌词会逐行高亮、平滑滚动居中
  • 逐字（精准）歌词：支持 ESLyric 的 <mm:ss.xx> 逐字标记（也兼容 [mm:ss.xx] 写法），当前行内已唱到的字逐个点亮
  • 翻译 / 音译：同一时间戳下的多行（原文 + 译文，或再加音译）会作为一组显示 —— 主行下方以更小更暗的副行呈现，整组一起高亮、一起居中，任何一行都不会被丢弃
  • 纯文本歌词：无时间轴的歌词以静态文本展示（不会误当作同步歌词而“末行恒亮”）
  • 点击跳转：点击任意歌词行可跳转到对应时间点播放
  • 歌词来源（本地优先）：先找音频同目录的同名 .lrc 与 %profile%\lyrics 歌词库 —— 你自己精修过的词优先，读文件也更快、不依赖网络；本地没有时才经页内桥接联网匹配（在线曲目按直链归属分发：QQ 音乐走 QQBridge，网易云走 NeteaseBridge —— 后者能用播放时记下的「直链 → 歌曲 id」映射按 id 精确取词）。桌面歌词窗口与 ESLyric 工具菜单需要 foo_uie_eslyric 组件
  • 多编码支持：内置 8 层编码检测引擎，可正确识别 GBK/GB18030、UTF-8、UTF-16 编码的 LRC 文件；其他亚洲双字节编码（Big5 / Shift_JIS / EUC）按评分制区分。含引号等特殊标签名也能正确定位
  • 右键菜单：在歌词面板或沉浸式页面的歌词区右键即可打开菜单 ——「翻译对齐方式」是一个二级菜单（鼠标悬停展开，当前项带 ✓）：自动识别（自动判断歌词格式）/ 标准双语（原词和翻译在同一时间）/ 兼容旧版（翻译在下一句时间）；再往下是 刷新歌词，以及三个二级菜单 / 条件项：歌词工具（搜索歌词… / 复制歌词 / 嵌入到歌曲标签 / 保存歌词到文件）、小窗（迷你播放器 / 歌词窗）、恢复自动匹配（手动挑过歌词时才出现），最后是 打开所在文件夹。选择按文件记忆，选「自动识别」即恢复。手动指定的两种模式按所选写法机械处理、不做语言分析（标准双语下同刻多行一律「首句为主、其余为副」），自动识别判不准的文件指定一下即可。歌词没有重复时间戳时（纯文本、逐字歌词等）不显示对齐这一项，因为此时不存在对齐问题
两种歌词格式：标准双语——原词与翻译写在同一时间戳下；兼容旧版——翻译被写在了下一句原词的时间戳上（TME / QQ 音乐等来源常见）。后者若按同刻归组，会把翻译当主行、下一句原词当成它的副行。主题会自动判断并统一成「原词为主、翻译为副」，并在菜单里显示识别结果；判断不出来时（例如未翻译的英文原词夹在日文行之间、整首只有部分句子有译文）可在菜单里手动指定，选择会被记住。
沉浸式播放
全屏沉浸体验，黑胶唱片与歌词两种模式
  • 进入沉浸模式：双击底栏左下角的封面，或点击右侧歌词面板封面左上角的沉浸按钮（单击底栏封面只是开合歌词面板）
  • 黑胶唱片模式：封面以黑胶唱片形式旋转，唱针动画随播放状态启停
  • 纯歌词模式：点击模式切换按钮，全屏显示歌词，适合跟唱
  • 3D 斜墙歌词：点右上角“显示模式”左侧的小圆钮，可把整块歌词切换成“贴在斜墙上”的 3D 透视效果（墙面朝向封面一侧），正在播放的那一行会从墙面微微鼓起，并带一层随封面主色调联动的柔光。开关状态自动记忆，默认关闭（关闭时与旧版渲染完全一致）
  • 内置控制：沉浸模式内含播放控制、进度条、频谱可视化
  • 轻松移动窗口：顶部新增拖拽条，按住可拖动窗口；双击拖拽条可最大化 / 还原
  • 退出：点击关闭按钮或按 Esc
频谱可视化
底栏实时频谱，以及沉浸页可切换的五种显示（频谱条 / 声场 / 瀑布图 / 示波器 / 矢量示波器）
  • 迷你频谱：显示在底栏，播放时实时跳动
  • 沉浸式频谱：沉浸模式下显示 32 条频谱柱，可切换五种显示（频谱条 / 声场 / 瀑布图 / 示波器 / 矢量示波器）—— 点它循环、右键直接挑；底栏那条迷你频谱固定为频谱条，点它不切换
  • 开关：点击底栏频谱按钮切换显示/隐藏，状态自动记忆
  • 设备切换自动恢复：接入音频解码器等切换输出设备时，频谱会在设备变更后自动重新订阅，无需重启主题
  • 使用对数压缩算法使频谱视觉更平滑，用 CSS transform 代替 height 重排以保证性能
插队队列与播放历史
右侧抽屉：插队队列（接下来播放）+ 上方可展开的播放历史

插队队列就是 foobar2000 的原生播放队列：全局、优先级最高，不属于任何歌单。播完一首自动移出一首，队列空了就回到中间列表（播放上下文）当前的位置继续 —— 所以"插队歌播完之后回到哪"永远是"你刚才在听的那张清单里那一首的下一首"，与随机 / 循环的档位一致。

  • 打开：点击底栏队列按钮或按 Q，右侧抽屉滑出
  • 插队：右键任意曲目 →「下一首播放」（插到队首）或「添加到插入队列」（追加到队尾）。两个动作都不动中间列表，可以放心在别的歌单里挑歌插队 —— 插队曲播完仍然回到你原本在听的那张清单继续，来源歌单不会因此变成播放上下文
  • 队列徽章：底栏队列按钮上显示数字徽章，超过 99 显示"99+"
  • 调整顺序：按住队列条目拖到目标位置（红色指示线标示落点），松手即按新顺序重建队列；悬停时条目左侧显示抓手图标；拖出列表区域松手视为取消，拖动中可按 Esc 取消，拖至列表上下边缘时自动滚动
  • 从队列移除：点击队列中曲目旁的删除按钮
  • 清空队列：点击抽屉顶部的清空按钮 —— 只清"待播"部分，不会打断正在播放的这首
  • 正在播放卡片：抽屉顶部固定显示当前播放曲目（封面 + 跳动均衡器），仅作展示，不参与排序也无法移除；下方列表全部为待播曲目
  • 空队列：抽屉会写明「当前无插队歌曲，将按中间列表顺序播放」—— 这也是"为什么播完插队歌没回到我原来的歌单"的答案：它一直按中间列表在走

播放历史是插队队列上方的那行按钮（默认收起，展开状态会记住）：点一下展开只读时间线，支撑「上一首」。

  • 展开 / 收起：点「播放历史」那行按钮 —— 展开时按钮高亮、箭头翻转；列表由旧到新向下排，最新一条紧贴下方的"正在播放"卡片，所以整条抽屉自上而下就是「过去 → 现在 → 接下来」
  • 记录规则：每播放一首记一条，连续同一首自动去重（单曲循环不会刷满），最多 20 条（「设置与工具 → 播放与队列 → 播放历史条数」可改成 10/20/50/100），存在本地、重启仍在
  • 上一首：点上一首 / 按 Ctrl+← 时，优先沿着历史往回找最近一首不同的曲目；历史到头才回到中间列表的上一首
  • 回到某一条：双击历史里的任意一条即可重新播放它（之后从那里继续往下记）
  • 清空：展开后右上角的清空按钮

QQ 音乐在线音源
搜索播放 · 勾选播放 · 无损下载 · 歌单导入

侧边栏「QQ 音乐」页就是入口：搜索 → 勾选 → 「在 foobar2000 播放」或「下载选中」。搜索 / 直链解析 / 歌词 / 封面全部在主题页面内完成（走宿主 foo_ui_webview2 的原生网络客户端），没有本地进程、端口、开关脚本，也不需要 node.js / Python —— 随 foobar 启动而在、关闭而消。

  1. 搜索：输入歌名 / 歌手 / 专辑后回车。底部「加载更多」把下一页追加到列表末尾（已勾选的不受翻页影响，可以跨页攒一批）；下方翻页条可整页跳转（上游不返回总页数，「下一页」按钮的可点状态由是否还有更多决定）。
  2. 勾选与播放：点行首复选框勾选（点整行也能勾），右侧「播放」按钮或双击整行 = 立刻播放这一首。点「在 foobar2000 播放」把勾选的曲目追加到固定的「QQ音乐」歌单末尾并从新曲开播 —— 之前播的歌原地保留，听完可以直接在歌单里接着选下一首。
  3. 下载：点「下载选中」逐首落盘到 <foobar2000 配置目录>\QQ音乐下载\（音频 + 同名 .lrc 一起写入；整目录可加进媒体库）。列表上方常驻「下载保存到 …」条，可一键打开文件夹或复制路径；下载中再点一次 = 停止（当前这首下完就停）。音质下拉框只影响下载。
  4. 导入自己的歌单：点「导入歌单」→「复制导出脚本」→ 到 y.qq.com 歌单页按 F12 打开控制台粘贴回车（脚本自动滚动抓全曲目，导出「歌名 - 歌手」每行一首）→ 回主题粘贴文本、指定目标歌单名 → 开始导入。逐首多轮搜索匹配（宁缺勿错），失败行会放回文本框可编辑重试，单次上限 300 首、随时可停。
  5. VIP / 无损：右上角「设置 Cookie」按面板说明操作 —— 浏览器登录 y.qq.com → F12 控制台运行 copy(document.cookie) → 把 Cookie 粘回面板保存。免费曲库不需要登录；Cookie 失效时表现为 VIP 曲目全部解析不到（重贴一次即可）。
  • 在线播放固定 MP3 流播：QQ 的 CDN 给所有直链打的 Content-Type 都是 audio/x-ogg，foobar2000 会按类型把 FLAC / AAC 直链误当 Ogg 拒解（提示「不支持的格式或文件损坏」），所以在线播放只解析 MP3 档（320 → 128）。要无损 / Hi-Res / 母带，请用「下载选中」落盘后本地播放（文件字节完好）。
  • vkey 过期：歌单里存的是带签名的 CDN 直链，约两小时过期 —— 过期条目再点会播放失败，回页面重新勾选播放即可刷新。想长期保存就下载落盘。
  • 封面与歌词自动匹配：在线曲目的封面由直链里的 mediaMid 反查腾讯图床（随播放 / 下载记录，缓存复用）；歌词按「标题 + 歌手 + 时长」多轮放宽搜索匹配，本地同名 .lrc 与 %profile%\lyrics 歌词库优先。歌词面板右键的「刷新歌词」会同时清掉在线匹配缓存。
  • 在线曲目没有本地文件：右键菜单的「编辑标签」「在资源管理器中显示」会置灰并说明原因，批量标签编辑自动跳过它们；星级评分、封面、歌词、波形、插队（下一首播放 / 添加到插入队列）都不受影响。需要改标签请先下载落盘。
  • 诊断入口：QQBridge.bridgeInfo()（版本 / 登录态 / guid / 各缓存条数与在途请求数）、CM.qqMusic.state（页面状态）、CM.artworkStatus()（封面兜底统计，rawFallback = 降级用原始 URL 的次数）、CM.lyricStatus()（最近一次歌词匹配）。
网易云音乐在线音源
在线无损 · 免登录额度更宽 · 贴链接导歌单

侧边栏「网易云」页是第二个在线音源入口，形态与「QQ 音乐」页一致：搜索 → 勾选 → 「在 foobar2000 播放」或「下载选中」。整条链路同样是页内桥接（js/netease-core.js + js/ui-netease.js），走宿主原生网络客户端，没有本地进程、端口、node.js。

  1. 搜索：输入歌名 / 歌手 / 专辑后回车。「加载更多」把下一页追加到列表末尾（已勾选不受翻页影响，可跨页攒一批），下方翻页条可整页跳转。网易云的搜索接口有限流（连打十几次会回「操作频繁」），桥接已把搜索串行化并留最小间隔；真被限流时状态栏会提示稍后再试，且只影响搜索 —— 直链 / 歌词 / 封面照常工作。
  2. 勾选与播放：点行首复选框或整行勾选，右侧「播放」/ 双击整行 = 立刻播放这一首。「在 foobar2000 播放」把勾选的曲目追加到固定的「网易云音乐」歌单末尾并从新曲开播（与「QQ音乐」歌单分开，一眼看得出曲目来自哪个平台）。
  3. 音质：下拉框有 标准 128K / 较高 192K / 极高 320K / 无损 FLAC / Hi-Res，同时作用于在线播放与下载（不像 QQ 页那样只能流播 MP3）。要不到的档位会自动降级，并按接口返回的真实档位回填，不会把降级结果报成无损；无损 / Hi-Res 需要会员登录。
  4. 下载：点「下载选中」落盘到 <foobar2000 配置目录>\网易云音乐下载\（音频 + 同名 .lrc 一起写入，歌词按歌曲 id 精确取词）。列表上方常驻「下载保存到 …」条；下载中再点一次 = 停止。
  5. 导入歌单：点「导入歌单」→ 粘贴歌单链接或 ID（如 https://music.163.com/#/playlist?id=3778678 或 3778678）→ 指定目标歌单名 → 开始导入。公开歌单与官方榜单免登录就能读到全部曲目，不需要 QQ 那种导出脚本；批量解析一次 10 首、并发 3 条，单次上限 300 首。
  • 会员曲目会明确标注：未登录 / 非会员时，会员曲目的直链接口照样返回一个能播的 URL，但内容是 30/45 秒片段。这类曲目在列表里标「VIP · 试听」，播放与下载都会跳过并说明原因（例如「仅 45 秒试听，需登录会员」）—— 不会往歌单里塞 30 秒的"歌"。列表里能完整播放的曲目会标出真实档位（如「320K」「无损」）。
  • 登录（要无损 / 会员曲目时）：点「登录 / Cookie」展开面板（与「QQ 音乐」页同一套最简模型：再点一次收起（与「导入歌单」共用同一套开关实现），面板里也有「收起」，面板与搜索 / 列表共存；取 Cookie 的步骤收在「怎么取？」里按需展开）—— 面板里填 Cookie —— F12 → 网络 / Network → 刷新 → 任选请求 → 右键「以 cURL 格式复制」→ 整条粘贴进面板（解析器会挑出 Cookie），或从 应用 / Application → 存储 → Cookie → https://music.163.com 复制 MUSIC_U。之所以不能"一条命令直接拿"：MUSIC_U 是 HttpOnly，页面 JS（含控制台）读不到，localStorage / sessionStorage / IndexedDB 里也没有副本。保存后当场校验：调账号 + 会员接口，回报「登录成功 + 会员有效期至 X」。
  • 在线曲目没有本地文件：右键菜单的「编辑标签」「在资源管理器中显示」会置灰并说明原因，批量标签编辑自动跳过它们；星级评分、封面、歌词、波形、插队（下一首播放 / 添加到插入队列）都不受影响。需要改标签请先下载落盘。
  • 诊断入口：NeteaseBridge.bridgeInfo()（版本 / 登录态 / 各缓存条数 / 限流剩余秒数 / 在途请求数）、NeteaseBridge.selfcheckState()（随页面加载跑的一次自检：搜索 / 解析 / 取词三步哪一步断了）、CM.netease.state（页面状态）。
