更新日志 · v2.2
自 v2.1 以来的功能优化与问题修复，重点覆盖媒体库分页、歌词显示、封面占位与歌单恢复
功能优化
  • 媒体库全面分页：专辑 / 艺术家 / 流派 / 歌曲 / 文件夹全部解除数量上限，改为客户端分页（每页 50 / 100 / 300 / 500，页码自动记忆）。
  • 浮动分页栏：分页按钮改为毛玻璃吸顶样式，滚动到列表任意位置都可直接翻页，无需回到顶部。
  • 歌曲列表分页：媒体库"全部歌曲"启用分页，跨页行号连续。
  • 文件夹浏览增强：面包屑导航 + "播放全部" + "添加到歌单"。
  • 启动恢复上次歌单：记住上次打开的歌单并按名称自动恢复，启动后播放列表不再空白。
  • 无封面占位图：无封面或封面加载失败时自动显示占位图，避免空框 / 闪空（底栏、歌词、沉浸式通用）。
  • 长歌词完整显示：沉浸式与歌词面板支持长句自动换行；当前句改用字号放大（重排布局），长句放大后完整可见、不被上下遮罩或相邻行遮挡。
  • 右键菜单可滚动：菜单过长时可滚轮滚动、在视口内自适应定位，"在线获取标签"等底部项不再被挡住。
问题修复
  • 专辑列表被 limit:200 硬上限截断 → 改为全量拉取 + 客户端分页。
  • 添加歌曲到歌单时菜单被 110ms 定时器提前隐藏、"界面闪退" → 修复第二层菜单隐藏时机。
  • 切换歌曲时歌单 UI 出现两行同时高亮 → 仅当前行保持播放状态。
  • 歌单表格启动为空（活跃歌单异步获取后未触发渲染）→ 启动自动渲染。
  • 锁定 / 自动歌单误显示"清空 / 删除 / 重命名 / 添加 / 排序"等无效操作 → 自动隐藏，仅保留播放。
  • 播放状态标记在含反斜杠 / 引号的路径上失效 → 改为按路径逐项比对。
  • ESLyric 桌面歌词启动失败（命令 GUID 失效后不再重探）→ 失败自动重新探测 + 提升命令命中率。
  • 动态频谱在接入解码器后失效 → 切换输出设备会中断宿主侧频谱流，现监听输出设备变更并自动重订阅频谱。
  • 不支持文件夹拖入 / 添加 → 宿主会把文件夹路径当单个音轨加入而报"格式不支持"，现自行递归枚举文件夹内的音频文件后再添加；拖放与"添加本地文件夹"菜单入口均支持，且去除重复添加。
  • 沉浸式页面无法移动窗口 → 新增顶部拖拽条，按住可拖动窗口、双击可最大化 / 还原。
性能与体验
  • 任务栏进度在高频播放事件中每次再到宿主 API → 仅在可见 1% 变化时推送，显著降低桥接开销。
  • 封面 / 分页 / 歌词等交互均采用事件驱动与 DOM 引用缓存，减少重复渲染与查询。
优化思路与借鉴
  • 参考优化版作者 贴吧用户_0DJXK1A 的优化版思路与设计，持续打磨媒体库、歌词与沉浸式体验。
  • 依据官方文档 foo_ui_webview2 快速开始 及音频 / 拖放 / 窗口相关 API 说明，调整频谱重订阅、路径拖放与窗口拖拽的调用方式，确保与 SDK v1.12.0 兼容。
界面导览
了解 CloudMusic 主题的四大区域布局
侧边栏
搜索框、导航入口（发现/播放列表/搜索/媒体库）、歌单列表
主内容区
4 个标签页切换显示不同内容，播放列表含封面、曲目表格、排序
歌词面板
右侧面板，显示封面、曲目信息和同步歌词，可点击歌词行跳转
底栏
曲目信息、播放控制、进度条、音量、频谱、队列按钮
播放控制
播放/暂停、快进快退、音量调节、播放顺序
  • 播放/暂停：点击底栏中央播放按钮，或按 空格
  • 上一首/下一首：点击底栏切换按钮，或按 Ctrl+← / Ctrl+→
  • 快进快退：按 ← 后退 5 秒，→ 前进 5 秒；也可拖动进度条
  • 音量：拖动音量滑块，或按 ↑ / ↓ 调节；按 M 静音
  • 播放顺序：点击底栏播放顺序图标，支持顺序播放、列表循环、单曲循环、随机播放
  • 播放后停止：在播放顺序菜单中可设置"播完当前曲目后停止"
播放列表
歌单管理、曲目排序、右键操作

播放列表是你的"收藏夹"，在侧边栏管理多个歌单，点击切换后在主区域查看曲目。

  • 新建歌单：侧边栏右键空白处或点击"+"按钮
  • 重命名/删除/清空：右键侧边栏歌单项
  • 排序：点击表头（标题/艺术家/专辑/时长/比特率）切换升序、降序、取消排序
  • 更多操作：点击歌单封面旁"..."按钮 — 随机排列、按标题/艺术家排序、撤销
  • 添加曲目到歌单：右键曲目 → "添加到歌单"；右键歌单 → "添加本地文件 / 添加文件夹"（文件夹会自动递归展开其中的音频文件）；或将音频文件 / 文件夹拖放到窗口任意位置
  • 从歌单删除：右键曲目 → "从歌单中删除"
三概念区分：媒体库是"仓库"（所有音频文件），播放列表是"收藏夹"（自定义分组），播放队列是"工作台"（即将播放的曲目）。
媒体库浏览
按歌曲、艺术家、专辑、流派多维度浏览

媒体库是 foobar2000 扫描的所有音频文件的集合，支持 5 种视图维度：

概览
显示媒体库统计数据：总曲目数、艺术家数、专辑数等
歌曲
按歌曲维度列表浏览，支持增量加载更多
艺术家
网格卡片展示，点击进入艺术家详情页查看其所有专辑和曲目
专辑
网格卡片展示，点击进入专辑详情页查看曲目列表
  • 进入详情：点击艺术家/专辑/流派卡片，进入后显示曲目列表和"播放全部"按钮
  • 返回列表：点击返回按钮，滚动位置会自动恢复到之前的位置
  • 刷新媒体库：更多菜单 → "刷新媒体库缓存"，重新扫描文件
搜索
在媒体库中快速查找曲目
  • 搜索入口：侧边栏搜索框（回车跳转搜索页）或切换到"搜索"标签页直接输入
  • 实时搜索：在搜索页输入框中输入，350ms 防抖后自动触发搜索
  • 搜索结果：显示匹配总数、封面、标题、艺术家·专辑、时长
  • 添加全部：搜索结果页提供"添加全部到歌单"按钮
  • 右键操作：搜索结果支持与播放列表相同的右键菜单（播放、加入队列、添加到歌单等）
歌词
同步歌词、纯文本歌词、点击跳转
  • 显示/隐藏：点击底栏歌词按钮或按 L 切换歌词面板，状态自动记忆
  • 同步歌词：带时间轴的 LRC 歌词会逐行高亮、平滑滚动居中，支持逐字高亮
  • 纯文本歌词：无时间轴的歌词以静态文本展示
  • 点击跳转：点击任意歌词行可跳转到对应时间点播放
  • 歌词来源：通过 ESLyric 组件获取，需安装 foo_uie_eslyric
沉浸式播放
全屏沉浸体验，黑胶唱片与歌词两种模式
  • 进入沉浸模式：双击右侧面板的封面图，或点击封面左上角沉浸按钮
  • 黑胶唱片模式：封面以黑胶唱片形式旋转，唱针动画随播放状态启停
  • 纯歌词模式：点击模式切换按钮，全屏显示歌词，适合跟唱
  • 内置控制：沉浸模式内含播放控制、进度条、频谱可视化
  • 轻松移动窗口：顶部新增拖拽条，按住可拖动窗口；双击拖拽条可最大化 / 还原
  • 退出：点击关闭按钮或按 Esc
频谱可视化
实时音频频谱柱状图
  • 迷你频谱：显示在底栏，播放时实时跳动
  • 沉浸式频谱：沉浸模式下显示 32 条频谱柱
  • 开关：点击底栏频谱按钮切换显示/隐藏，状态自动记忆
  • 设备切换自动恢复：接入音频解码器等切换输出设备时，频谱会在设备变更后自动重新订阅，无需重启主题
  • 使用对数压缩算法使频谱视觉更平滑，用 CSS transform 代替 height 重排以保证性能
播放队列
管理即将播放的曲目
  • 打开队列：点击底栏队列按钮或按 Q，右侧抽屉滑出
  • 加入队列：右键任意曲目 → "下一首播放"，曲目插入队列顶部
  • 队列徽章：底栏队列按钮上显示数字徽章，超过 99 显示"99+"
  • 从队列移除：点击队列中曲目旁的删除按钮
  • 清空队列：点击队列抽屉顶部的清空按钮
  • 状态标记：队列中正在播放的曲目有高亮标记，已播放的曲目有标记
标签编辑
查看和修改单首曲目的元数据标签
  1. 右键任意曲目（播放列表、搜索结果、媒体库均可）
  2. 选择「编辑标签」，弹出标签编辑面板
  3. 面板自动读取并显示当前所有标签字段
  4. 修改需要更改的字段，清空内容表示删除该标签
  5. 点击「保存」写入文件，自动刷新播放列表显示

支持编辑的标签字段：

基本信息
标题、艺术家、专辑、专辑艺术家
分类信息
流派、年份、音轨号、CD 号
扩展信息
作曲、备注
封面管理
查看、更换、移除嵌入封面（见封面管理章节）
标签写入为异步操作，保存后面板会自动关闭并在写入完成后刷新播放列表。只有实际修改的字段才会被写入文件。
批量标签编辑
多选曲目后统一修改标签
  1. 在播放列表中按住 Ctrl 点击多首曲目，选中行高亮显示
  2. 选中 2 首及以上时，底部浮出批量操作栏（显示已选数量）
  3. 点击「批量编辑标签」打开批量编辑面板
  4. 勾选需要修改的字段前方的复选框，填写新值
  5. 未勾选的字段保持原值不变，点击「保存」批量写入
  • 取消选择：点击批量操作栏的"取消选择"，或按 Esc
  • 右键菜单入口：有多选时，右键菜单也会显示"批量编辑标签"选项
  • 写入结果：保存后显示成功/失败计数，部分失败时会提示
封面管理
查看、更换、移除嵌入封面

封面管理集成在单曲标签编辑面板中，打开标签编辑器后可在顶部看到封面区域。

  • 查看封面：打开编辑面板时自动加载当前嵌入封面预览
  • 更换封面：点击"更换封面"按钮，选择本地图片文件，自动嵌入为 front 封面
  • 移除封面：点击"移除封面"按钮，确认后移除所有嵌入封面
封面嵌入支持 FLAC、MP3 等主流格式。部分格式可能不支持嵌入封面操作，失败时会弹出提示。
在线标签获取
通过 foo_freedb2 从在线数据库自动补全标签
  1. 右键任意曲目
  2. 选择「在线获取标签」
  3. 系统自动搜索并调用 freedb 在线数据库
  4. 在弹出的窗口中完成标签匹配和写入
需要安装组件：此功能依赖「在线标签获取器」(foo_freedb2) 组件。未安装时点击会弹出提示弹窗。首次调用后命令会缓存，后续使用无延迟。
星级评分
1-5 星评分与"喜欢"功能
  • 评分：右键曲目 → "评分"区域，点击 1-5 星
  • 清除评分：右键曲目 → "清除评分"
  • 喜欢按钮：底栏爱心按钮，点击=评 5 星，再次点击=清除评分（评分 ≥ 4 星视为"喜欢"）
  • 评分存储：优先存储在 foo_playcount 统计中，回退写入文件 RATING 标签
需要安装组件：评分功能依赖 foo_playcount 组件。未安装时会弹出提示。
EQ 均衡器
内置均衡器调节
  • 打开：更多菜单 → "均衡器"
  • 开关：在弹出的菜单中切换 EQ 开启/关闭
  • 通过 foo_dsp_eq 组件实现，状态自动同步
输出设备
切换音频输出设备和模式
  • 打开：更多菜单 → "输出设备"
  • 显示当前输出模式、设备名称、位深、缓冲长度
  • 支持 ASIO、DSD 等输出模式（取决于已安装组件）
桌面歌词
独立悬浮窗口显示歌词
  • 开关：更多菜单 → "桌面歌词"，再次点击关闭
  • 调用 ESLyric 原生桌面歌词功能，独立悬浮窗口显示
  • 首次使用时自动搜索并缓存命令，后续无延迟
需要安装组件：桌面歌词依赖 ESLyric (foo_uie_eslyric) 组件。未安装时会弹出提示弹窗。
拖放添加文件
拖拽音频文件或文件夹到窗口
  • 添加文件：将音频文件拖拽到窗口任意位置
  • 添加文件夹：将文件夹拖入后自动递归枚举其中的音频文件再添加，不再把整个文件夹当作单曲导致播放失败
  • 窗口悬浮遮罩：拖入时显示半透明提示"松开以添加到当前播放列表"
  • 支持所有 foobar2000 支持的音频格式；文件添加到当前正在查看的播放列表，并去除同一批文件的重复添加
