# foobar2000 Web Theme

Fork 自 [基于插件foo-ui-webview2制作的主题](https://gitee.com/lqs_linzh/foobar2000_web_theme)，修改了部分内容，使其更符合个人口味。

`featrue` 分支为修改版，`master` 分支为上游版本。

## 使用方法

1. 下载主题文件，将 `default` 文件夹解压到 `Foobar2000/profile/webview-ui` 目录下
2. 打开 `Foobar2000` ，在 `参数选项` -> `显示` -> `WebView2 UI` -> `Web 模板` 中选择 `default` 主题
