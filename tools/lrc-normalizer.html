空格 / 回车 / 点按钮 = 给目标行打上当前播放时间，打完自动跳下一句 · Backspace = 撤销上一次 · P = 播放/暂停 · ← → = ∓3 秒（按住 Shift 微调 0.5 秒）· S = 从此行播（回到该句前 1.2 秒）
下面的歌词列表点任意一行 = 从那一句开始打（重打某几句时用）；译文行在勾选「跳过译文行」时不会被停下来，会自动跳过。
逐字模式：给每个字 / 每个词按一次 空格，打在它开始唱的时刻 —— 打完最后一个字自动跳下一句，译文行整句跳过。
Backspace = 退回上一个字 · S = 从当前字前 1.2 秒播 · 上排工具条的 逐字歌词 勾选框开关本模式（勾上后导出为 [mm:ss.xx]<mm:ss.xx>字… 增强型 LRC，译文行按同刻整句写）。只想整句打也行：每句只按一次，那行就按整句导出。
点一行 = 从那一句开始打轴（当前目标行高亮）
规则（机械，不做语义判断）：译文 = 挂在它上面最近一条「主歌词」后面；导出时「标准双语」把译文时间改成主歌词的时间，「兼容旧版」把译文改成下一句主歌词的时间。 粘贴的纯文本没有时间戳，所有行就是 00:00.000；在「打轴」页边听边按空格把它们排出来即可。
松开鼠标即可载入（音频 → 歌曲，.lrc / .txt → 歌词）

粘贴歌词文本

每行一句，直接从网页 / 记事本复制粘贴即可。带 [mm:ss.xx] 时间戳的行按时间戳解析，之后可以在「打轴」页重打； 不带时间戳的纯文本会把所有行的时间戳设为 00:00.000，等你去「打轴」页跟着音乐按空格逐个打。
粘贴的是「原文一行、译文一行」交替的双语歌词时，导入后点工具条上的 交替配对 就能把译文行标出来（首行角色不对就先点一下首行徽标再配对）。
